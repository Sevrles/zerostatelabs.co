# .impeccable.md — Zero State Labs site

## Design Context

### Users
Technical founders, operators, and enterprise buyers evaluating an AI systems studio. They scan fast, hate hype, and judge craft instantly. Viewed mostly on desktop, in work contexts.

### Brand Personality
"Quiet, sharp, unimpressed." Revenue-first. Ships, doesn't pitch. Atlanta-rooted.

### Aesthetic Direction
- **BRUTALIST WITH COLOR POPS — user mandate (Aug 2026 review):** industrial paper + near-black ink as the base, ONE saturated signal color per page (signal orange, acid lime, cobalt, hot magenta, volt, safety red). Muted/weathered palettes REJECTED ("neo soul coffee shop"). No gradients, no glow — flat color blocks, hard edges, zero radius.
- **Type:** heavy condensed display (Anton / Archivo Black / Bricolage Grotesque 800) + raw mono (Martian Mono). Fraunces REJECTED ("the type isn't doing it"). Text treatments: stretch, outline, collide, marquee, stack, giant numerals.
- **Theme:** paper-light default, one or two dark-inverted sections per page.
- **Anti-references:** Tron/manga (rejected), Y2K glass (rejected), muted cafe palettes (rejected), Inter, purple-blue gradients, gradient text.

### Design Principles
1. One unforgettable typographic moment per page — everything else supports it.
2. Paper + ink base, ONE loud accent. Color pops are rare and they hit hard.
3. Revenue-first voice: no "unlock/power/seamless" language. Copy names real systems (Ghost, Curlspirations, PoseDirector).
4. Motion is ambient or entrance-only, respects prefers-reduced-motion, transform/opacity only.
5. Machine readability is non-negotiable: JSON-LD, semantic HTML, single h1.
