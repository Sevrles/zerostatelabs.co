# .impeccable.md — Zero State Labs site

## Design Context

### Users
Technical founders, operators, and enterprise buyers evaluating an AI systems studio. They scan fast, hate hype, and judge craft instantly. Viewed mostly on desktop, in work contexts.

### Brand Personality
"Quiet, sharp, unimpressed." Revenue-first. Ships, doesn't pitch. Atlanta-rooted.

### Aesthetic Direction
- **Muted, weathered palettes only** — no absolute/saturated colors. Dark-leaning preferred; off-white/cream acceptable. Approved hue families: off-pink (Earthed Rose), dusty blue (Mist/Dusty Blue), cream/bone, plum, sage, clay, espresso. Research basis: 2026 "Cloud Dancer"/atmospheric palettes.
- **Type:** Fraunces (variable serif, italic contrast) + IBM Plex Mono — USER MANDATE (approved in review; overrides reflex-font bans). Display serif is the brand voice.
- **Text display systems are the differentiation** — each page owns one: kinetic variable weight, vertical mode, circular path, outline/fill collision, giant numerals, letter stagger, text-as-texture, blend-mode overlap, tilted type, multi-speed tickers.
- **Theme:** dark default for most, cream/paper for three. Chosen per page, never default.
- **Anti-references:** Tron/manga aesthetic (user-rejected), Y2K glass (user-rejected), purple-blue gradients, Inter, generic AI-slop cards, gradient text.

### Design Principles
1. One unforgettable typographic moment per page — everything else supports it.
2. No absolute colors. Every color is weathered, tinted, or dimmed.
3. Revenue-first voice: no "unlock/power/seamless" language. Copy names real systems (Ghost, Curlspirations, PoseDirector).
4. Motion is ambient or entrance-only, respects prefers-reduced-motion, transform/opacity only.
5. Machine readability is non-negotiable: JSON-LD, semantic HTML, single h1.
