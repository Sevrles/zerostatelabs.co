# .impeccable.md — Zero State Labs site

## Design Context

### Users
Technical founders, operators, and enterprise buyers evaluating an AI systems studio. They scan fast, hate hype, and judge craft instantly. Viewed mostly on desktop, in work contexts.

### Brand Personality
"Quiet, sharp, unimpressed." Revenue-first. Ships, doesn't pitch. Atlanta-rooted.

### Aesthetic Direction
- **MODERNIZED BRUTALISM — current direction (Aug 2026 review 3):** hard 3px borders + hard offset shadows (4px 4px 0), zero radius, industrial paper + near-black ink + ONE signal color per page (signal orange / cobalt / volt / magenta / acid). Raw structure, polished craft: expo easing, refined spacing, SVG motifs. Muted/weathered palettes REJECTED ("neo soul coffee shop").
- **BRANDING SYSTEM (user-approved elements from the original site):** SVG mark (Z inside a zero-circle) with stroke draw-on animation, per-letter wordmark rise, canvas 2D starfield with mouse parallax (no Three.js). Logo as interface: hover rotation, scroll parallax ghost mark, boot-settle animation.
- **Type:** Anton (display) + Martian Mono (labels). NO outline/stroke letters (user-rejected). Solid fills, highlight chips, hard-shadow text allowed.
- **Theme:** paper-light default, dark pages per concept.
- **Anti-references:** Tron/manga (rejected), Y2K glass (rejected), muted cafe palettes (rejected), raw unfinised brutalism (too familiar), Inter, purple-blue gradients, gradient text.

### Design Principles
1. One unforgettable typographic moment per page — everything else supports it.
2. Paper + ink base, ONE loud accent. Color pops are rare and they hit hard.
3. Revenue-first voice: no "unlock/power/seamless" language. Copy names real systems (Ghost, Curlspirations, PoseDirector).
4. Motion is ambient or entrance-only, respects prefers-reduced-motion, transform/opacity only.
5. Machine readability is non-negotiable: JSON-LD, semantic HTML, single h1.
